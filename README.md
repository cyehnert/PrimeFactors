This program enables the user to factor any number up to 50 digits in length into its
prime factors. The number can be typed into the input line directly, or it can be 
constructed by the code. In addition to receiving a string of digits, the code also
accepts expressions of the form a^b-c or a^b+c. This makes it easier to explore
the Mersenne primes. All of the Mersenne primes up to and including M12 can
be tested in the code.
